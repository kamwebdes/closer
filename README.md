# Closer Estimates

Estimate app for solo tradespeople. Installable web app (PWA) with accounts, automatic backup and customer approval links, powered by Supabase.

- `index.html` – the app
- `approve.html` – the page customers see when you text them an approval link
- `setup.sql` – run once in Supabase > SQL Editor to create the database tables
- `manifest.webmanifest`, `sw.js`, `icons/` – install and offline support

Bump `VERSION` in `sw.js` whenever you upload changed files.
